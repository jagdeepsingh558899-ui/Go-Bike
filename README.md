# GO BIKE

Premium India-focused ride-hailing platform built as a real connected
web/PWA application.

Go Bike is designed for customers, drivers and administrators with
Firebase-powered authentication, realtime ride synchronization,
driver GPS tracking, ride management, payments architecture and
administration.

---

## 1. PROJECT OVERVIEW

Go Bike provides a complete ride-hailing workflow:

Customer:

Login
→ Home
→ Select service
→ Pickup
→ Drop
→ Fare estimate
→ Request ride
→ Find driver
→ Driver accepts
→ Driver live location
→ Driver arrives
→ 4-digit OTP
→ Ride starts
→ Live ride
→ Drop
→ Ride completion
→ Payment
→ Rating
→ History

Driver:

Login
→ Approval check
→ Home
→ Go Online
→ Receive ride request
→ Review request
→ Accept ride
→ Navigate to pickup
→ Arrived
→ Verify customer OTP
→ Start ride
→ Navigate to drop
→ Complete ride
→ Earnings
→ History

Admin:

Secure login
→ Dashboard
→ Driver approvals
→ Users
→ Live rides
→ Fare settings
→ Commission
→ Payments
→ Reports
→ Notifications
→ System management

Go Bike must operate as one connected system rather than a collection
of disconnected HTML pages.

---

## 2. PRODUCT PRINCIPLES

The project follows these principles:

1. Real backend functionality.
2. No fake ride acceptance.
3. No fake GPS locations.
4. No fake payment success.
5. No frontend-only authentication.
6. No client-trusted admin role.
7. No client-trusted driver approval.
8. No client-trusted fare or commission.
9. No client-only OTP validation.
10. Strict ride state transitions.
11. Atomic driver acceptance.
12. Realtime customer/driver synchronization.
13. Mobile-first UI.
14. Responsive desktop support.
15. PWA support.
16. Secure Firebase rules.
17. Minimal duplicate code.
18. One canonical version of every file.
